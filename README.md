# Sebastians_Personalized_ELK_Code
This repository contains modifications to the ELK to support my reserach.

Changes include:

- Implementation of task 24 (computation of the expansion coefficients of the second variational eigenvectors for the computation of the spintexture along a k-path)

- Implementation of task 26 (computation of the momentum and band-resolved orbital and atom-projected densitites for the computation of band-structure resolved tensor-moments)

- Implementation of task 103 (adapted from task 100, 101: modified version of the fermi-surface routine for research of Sr2RhO4 and Sr2RuO4)

- Implementation of task 901 (computation of the momentum and band-resolved magnetization-density in a real-space plane)

- Implementation of a new input variable that enforces the state to be time-reversal symmetric (can be helpful if the system tends to a magnetic state due to bad initial conditions)
